# 第六十轮 — 启动动画: 八卦转盘演算今时卦 (v1.50.0 待发布)

## 需求: "加一个启动动画，点击启动之后显示八卦转盘，算出今日卦象，然后进入主页"

## 设计决策 (AskUserQuestion 用户全选推荐项)

- 卦象口径: 沿用 hourHex(now) 时辰卦, 与主页 todayHex 严格同源 (零风险);
  文案用「今时起卦」(现状 hour%16 只按小时, 与日期无关 — 已在设计阶段向用户说明)
- 播放策略: 每次冷启动都播, 右上「跳过 ›」
- 收尾: 六爻 Hero 飞入主页今日一卦卡
- 方位: 先天八卦 (乾兑离震巽坎艮坤, 与 kXiantian 梅花先天数一致)

## 实现

- **core/bagua.dart**: kBaguaXiantian (name/nature/bits 三爻自下而上) + baguaIndexOf
- **view/splash/bagua_painter.dart**: 纯 CustomPainter 双层转盘 — 外环 8 卦符
  (水平绘制)、内环 8 自然名 (TextPainter)、中心太极 S 弧、固定朱砂指针、
  停位金圈/朱砂卦符高亮; 无图片/无 blur
- **view/splash/bagua_splash.dart**: 单 AnimationController 2850ms
  (spin Interval(.09,.65, easeOutExpo) 外环顺时针 2 圈停上卦 / 内环逆时针
  2 圈停下卦; reveal Interval(.65,.82) 六爻 HexGlyph(animated) + 卦名);
  跳过按钮、4s watchdog、disableAnimations 直接进主页;
  PageRouteBuilder 裸路由 (450ms) 让 Hero 承担过渡
- **main.dart**: 通知冷启动 launchPayload != null → skipSplash 直接 AppShell
  (避免提醒点击还要等 3 秒, 也不吞 AppShell 的 payload 直达逻辑)
- **theme/yijing_theme.dart**: YiMotion.dailyHexHero 共享 tag; home_screen
  的 HexGlyph 包 Hero

# 第六十一轮 — 太极修复 + 全应用复古玄幻美化 (代码完成, 未验证/未发布)

## 需求: "中间的太极阴阳鱼都变形了，继续对整个应用进行美化设计，更复古玄幻风格，符合道家风格"

## 根因与修复

- **变形根因**: 两处太极都用 Path.arcTo 拼 S 曲线, arcTo 起点与当前点
  不连续 → 自动插入直线段, 阴阳鱼被拉成畸形; 且转盘太极之后又画了一个
  中心墨圆盖住鱼眼。
- **标准叠画法** (新 theme/yi_ornament.dart paintTaiji): 全金底 →
  drawArc(useCenter:true) 右半阴扇形 → 上半阴鱼头圆 → 下半阳鱼头圆 →
  两眼 → 外郭; 几何恒定, 只用 drawArc/drawCircle, 不再用 arcTo。
- 接入: view/splash/bagua_painter.dart (转盘中心)、
  view/widgets/coin_toss_anim.dart (铜钱背面太极), 两处坏 Path 全删;
  转盘删掉遮眼的中心墨圆。

## 美化 (全局 token 驱动, 一处生效全应用)
