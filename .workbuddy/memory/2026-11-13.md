# 2026-11-13 — iter74 (v1.65.0) P2 设计系统收敛

## 决策: 严格视觉等价, 不借重构改设计

双扫描发现的 4 类重复组件里, chip 的**视觉参数其实各不相同**
(圆角 8/10/17/18, 激活透明度 0x33/0x2A/0.18, 有无圆点/计数/双行文字).
所以做成**参数化组件**而非强制统一外观; 近似色合并 (0x22/0x2A/0x33/0x55/0x88
五种激活透明度) 属设计变更, 需要视觉评审, 本轮一律不动.
`transform_screen` 的卦序格是「网格单元」不是筛选 chip, 语义不同, 没有硬塞进组件.

## 改动

- 新 `lib/view/widgets/yi_kit.dart` (放 view/widgets 而非 theme, 避免 theme 反向依赖 view):
  - `YiFilterChip` 参数: accent/count/dot/radius/padding/activeFill/inactiveTextColor/
    inactiveBorderColor/letterSpacing/inkWell/center — 覆盖卦库、历史、详情三处
  - `YiEmptyState`: seal/message/hint/messageStyle — 覆盖卦库、历史两处
    (me_screen 的「暂无数据」是图表内嵌空状态, 视觉不同, 未抽)
  - `YiSectionTitle`: icon/color/divider/padding — 覆盖设置面板、我的、历史三处.
    **坑**: 纯文字变体必须直接返回 `Text`, 不能返回 `Row`, 否则调用方把它嵌在父
    Row 里会拿到无界横向约束.
- 删 5 处 `_card()/_cardDeco()` 转发, 调用点直接 `yiCardDecoration(...)`
  (`yiCardDecoration()` 本就是单一装饰源, 再包一层 widget 属过度设计).
- `yijing_theme.dart` 补 `YiColors` 8 个语义色 (inputBg/sheetBg/onFill/activeTint/
  activeTintSoft/gridCellBg/gridCellBorder/gridCellActiveBorder) + `YiType`
  (section/chip/hint/caption/body) + `YiSpacing` 刻度.
  **14 处完全同值硬编码色清零** (grep 验证非 theme 文件残留 = 0);
  269 行 fontSize 与 60 行 Duration 的渐进收敛未做 — 全量替换风险大、收益边际,
  本轮只在新组件内落地 token.
