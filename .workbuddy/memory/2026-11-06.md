# 第六十三轮 — 显示效果与动画继续优化 (v1.51.0)

## 需求: "继续优化显示效果与动画"

## 实现

- **Tab 切换修真问题**: golden 中间帧 (90ms) 发现 IndexedStack 只绘制当前页,
  交叉淡入在切换中段出现「半透明新页 + 墨底」发虚空白。改为**整页不透明
  滑入 + 缩放归位** (去掉 AnimatedOpacity, 保留方向 7.5% 侧滑 + 1.5% 缩放,
  280ms easeOutExpo), 内容自第一帧完整可见
- **启动转盘定盘反馈**: 上下卦停位金圈各加一圈随 reveal 扩散淡出的涟漪,
  朱砂指针加扩散脉冲光环 (与铜钱落定涟漪语言统一)
- **主页入场错峰**: homeStagger 四段→五段 (新增 500ms), 卦语横幅单独错峰
- **减少动画统一**: YiMotion.reduced(context, d) 压零; StaggerIn / _fadeTab /
  SwipeBackPage 全部尊重系统 disableAnimations
- **显示效果提亮**: 双金线 alpha 0.16→0.26、边框 0.8→1.0;
  星宿点 alpha 0.06~0.13→0.09~0.18、云弧 0.055→0.075、角卦符 0.07→0.09
  (实机上一版偏淡)
