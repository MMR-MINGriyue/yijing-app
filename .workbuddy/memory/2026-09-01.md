# 2026-09-01 第二十四轮迭代 — 横屏矮屏适配 (v1.21.0)

## 问题

手机横屏 (iPhone 12 844×390 / SE 667×375) 在原三态布局模型下体验崩坏：
- app 模式 media query `@media (max-width: 900px)` 触发横向 scroll-snap 轮播
- 每屏 `flex: 0 0 100%` → 844px 全宽铺满, 内容 max-width 460px 居中 (两侧大片死黑)
- 高度 390px 极矮, hero-card (355px) + quick-row (103px) + recent (210px) 全部挤出, adjustHomeScroll 把 hero 完全滚出去
- 7 屏单列轮播在横屏视口下毫无价值, 横向只能用 swipe 来回切

## 方案

新增独立 media query: `@media (orientation: landscape) and (max-height: 520px) and (max-width: 1200px)` —
- 复用 grid 模式的多列网格布局 (flex-wrap: wrap + gap 16px + padding 16px)
- 每屏 390px 宽 × `calc(100dvh - 32px)` 高 (约 358px), 保持竖屏原比例 + 边框圆角
- 关闭 scroll-snap / overflow-x / app-pager / app-hint
- 视口纵向滚动: scrollHeight 1652px, 滚到底可看第 7 屏
- 临界值: 844 宽可 2-3 列; 667 宽自动单列; 平板横屏 1024×500 走原 grid 模式 (min-width 901 触发, 不会被本规则干扰); 正方形 500×500 不触发

  - B. 667×375: 7 屏 / 390 宽 / 单列

## C. 关键 CSS 调试坑

**坑 1: 矮屏 block 覆盖横屏规则**
- landscape block 原本在 short-screen block 之前
- 横屏视口 844x390 同时命中 `@media (orientation: landscape) and (max-height: 520px)` 和 `@media (max-width: 900px) and (max-height: 740px)`
- 同特异性下后定义胜出 → 矮屏规则的 .hero-card { padding: 16px... } 覆盖了横屏的 10px 紧凑
- 解决: 整个 landscape block 移动到 short-screen block 之后, 横屏规则后定义胜出

**坑 2: `[hidden]` 默认 display:none 被覆盖**
- `.method-list { display: flex }` 会覆盖 HTML5 `[hidden]` 的默认 display:none
- 设置 `moreList.hidden = true` 后, 元素仍然 visible (因为 display:flex 优先)
- 修复: 显式 `.method-list[hidden], .bazi-form[hidden], ... { display: none !important }`
- 测试截图才正确反映子页切换 (之前一直显示默认视图但 hidden 已设置)

**坑 3: iter21 G 部分 gotoScreen 参数错**
- 之前用 `gotoScreen(2)` 想跳到屏2 (起卦), 实际是 64卦 (屏3, index=2)
- 改为 `gotoScreen(1)` 跳到屏2, 加 moreDivEntry 检查 (F 部分 recallBazi 已进子页, gotoScreen 不重置 hidden, 故保留即可)
