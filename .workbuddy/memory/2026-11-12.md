# iter73 (v1.64.0) — P1 性能迭代

## 重建热点 (4 处)

1. **hexgrid** `hexgrid_screen.dart`: GridView.builder 的 key 原为
   `'palace|keyword|list.length'`, 搜索逐字符就销毁整个 64 格 Element 树并重播入场动画.
   改 `ValueKey('hexgrid_$palaceFilter')` (只随宫筛选变), item 用 `ValueKey('grid_item_$no')` 复用.
2. **swipe_back** `swipe_back.dart`: 原每帧 `setState(() => _dx = ...)` 重建整页.
   重写为 `ValueNotifier<_SwipeState(dx, dragging)>` + `ValueListenableBuilder`,
   GestureDetector + 页面内容作为 builder 的 `child` 缓存 → 拖拽期间页面内容零重建.
   注意 duration 依赖 dragging, 所以两个字段必须放同一个 notifier 对象里.
3. **history** `history_screen.dart`: 全量 `ListView(children:)` → `ListView.builder`;
   记录区 `_rowAt(index, list, g1, g2)` 按索引惰性构造 (分组标题/空状态/时间轴行).
   `IntrinsicHeight` → `Stack`: 右侧 `_recordCard` 作 non-positioned child 决定高度,
   左轨 `Positioned(left:0,top:0,bottom:0,width:40)` 拿到有界高度后 `Expanded` 直接拉伸,
   省掉双次布局. 原有 `tl_day_/tl_dot_/tl_rail_/hist_` key 全部保留.
4. **app_shell**: 4 个 Screen Widget 提取为 `late final List<Widget> _screens`,
   切 Tab 只重建轻量 `_fadeTab` 的 AnimatedSlide/AnimatedScale 外壳
   (不敢缓存外壳本身, 因其 offset/duration 依赖 `_tab`).

## 重复计算 (4 处)

- **HistoryRepository.version** (`_bump()` 在 add/removeMany/clearReal/mergeAll) +
  **HistoryViewModel 派生缓存**: `_sync()` 以 `version|年月|6 个筛选态|当天日期` 为失效键,
  一次全表扫描算出 monthAll/hexChips/dirChips/typeChips/filtered/total/week/monthCount.
  关键: 外部写入 (CastViewModel 落历史) 没 notify 也能靠 version 自动失效, 不 stale.
  缓存列表按约定只读 (代码库内无就地修改调用).
- **share_card**: `_wrapCentered` 逐字符 `new TextPainter + layout()` → 二分找最长不超宽前缀
  (O(n) → O(行数·log n)), 并复用 `_measureTp` 实例. 断行语义与原实现等价
  (单字超宽仍强制收 1 字; `substring` 与 `split('')` 同为 UTF-16 code unit).
- **bazi**: `nayinOf` 60 对线性扫 → `_kNayinMap` 一次建索引.
- **home**: 黄历 `almanacOf(DateTime.now())` 从 view 挪进 HomeViewModel `almanac` getter,
  按「日期+时辰」缓存 (key 含 `(hour+1)~/2`), 跨时辰失效; 顺便统一到可注入时钟 `_now`.

## 为什么没做另外两项 (有意为之, 不是遗漏)

- **8 屏 `_onVm() => setState(() {})` 全量改细粒度监听**: 会把 ChangeNotifier 架构翻成
  ValueNotifier 分片, 牵动 230 个测试的时序; 本轮用「派生缓存 + 稳定 Widget 实例 +
  局部刷新」把最痛的三条路径 (搜索/拖拽/切 Tab) 解决掉, 全量重构留独立迭代.
- **bazi / 分享卡移 UI isolate**: `compute()` 是同步 void 且被 UI 与测试直接调用,
  改 async 会级联破坏时序; 分享卡 `dart:ui` 的 PictureRecorder/toImage 在 background
  isolate 的可用性需要真机帧率验证. 本轮先用二分测量/查表/缓存把主线程开销降下来.
