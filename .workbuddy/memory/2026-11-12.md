## P0 六项修复 (均已加回归测试)

1. **冷启动污染历史** `bazi_viewmodel.dart`: 构造 `_boot()` → `compute()` 无条件
   `repo.add(HistoryRecord(type:'bazi'))`, 每次冷启动多一条. 拆 `compute({bool logHistory = true})`,
   `_boot()` 用 `logHistory:false`; 同时把 boot Future 存为 `late final ready` 供测试 await
   (原 fire-and-forget 不可观测).
2. **当日卦语跨日不失效** `home_viewmodel.dart`: `_quoteHex ??= _computeQuote()` 永久缓存;
   加 `_quoteDay`, getter 比对 y/m/d 自动失效; `retime()` 仍只 notify. `_computeQuote(DateTime)` 显式传时刻.
3. **fire-and-forget 写入** 新建 `data/prefs_io.dart`: 串行队列 `enqueuePrefsWrite(key, value)`
   + `flushPrefsWrites()` + 全局 `onPersistenceError` 回调; `setString` 返回 false 也当错误.
   4 处 `.then((p) => p.setString(...))` 全部改 `unawaited(enqueuePrefsWrite(...))`.
   `write()` 接口保持 void (避免级联改 repository→VM→213 测试), main() 注入 FlutterError.reportError.
4. **起卦 pending 状态机** `cast_viewmodel.dart`: `setMethod()`/`reset()` 清 `_pendingRes/_pendingHex`;
   `finishCast()` 加 `phase != casting → return` 守卫, 防换占法后误落旧卦 / 重复回调重复落库.
5. **问候称呼硬编码** 新建 `data/profile_store.dart` + `profile_store_prefs.dart` (单例, 与
   PrefsBaziBirthStore 同款); SettingsViewModel 增 `greetingName/setGreetingName`, 设置面板加输入框,
   HomeViewModel 注入 `ProfileStore`; main() 的 Future.wait 增 `profileStoreFactory().warmUp()`.
   默认仍是「慕白」, 空名回落默认.
6. **CI 质量门** `.github/workflows/flutter-build.yml`: `flutter analyze ... || true` 去掉,
   并补 `set -o pipefail` (否则 tail 仍吞退出码). analyze 现在真正阻塞发布.
