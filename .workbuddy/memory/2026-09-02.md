# 2026-09-02 第三十二轮迭代 — Flutter 屏 6 历史记录重写 (v1.29.0)

## 背景

延续 iter30/31 Flutter 实验田, 用户说"继续"——挑最复杂屏 6 验证"功能密度屏"迁移成本. 屏 6 是易道 PWA 功能最密集屏: 月份导航 + 三层筛选 (卦象/方向/占法) + 搜索 + 排序 + 统计 + 收藏, 加 mock 数据, 屏 6 在易道代码也最重 (js/04-history.js 1273 行).

## Flutter 实现 (MVVM)

```
lib/
├── model/history.dart                   HistoryRecord + type 枚举
├── data/history_repository.dart         mock 9 条 (本月 5 + 上月 4, 含 8 卦象 + 1 八字 + 1 小六壬)
├── viewmodel/history_viewmodel.dart     HistoryState + 动态 chips + 筛选 + 排序
└── view/history_screen.dart             4 色统计卡 + 月份导航 + 搜索 + 3 类 chips + 历史卡列表

test/history_viewmodel_test.dart         9 项 ViewModel 单元测试
tool/verify_engine.dart                  26 项 (新增 6 项 history 数据验证)
```

**核心设计决策**:

1. **Mock 数据替代 localStorage**: Flutter web/移动端用 `dart:html` / `shared_preferences` 都增加依赖. 屏 6 实验田用 9 条 mock 数据验证 UI, 用 HistoryRepository 抽象 (真实环境替换为 SharedPreferences 实现即可)
2. **HistoryViewModel 持全部 UI 状态**: 年月/卦象筛选/方向筛选/占法筛选/关键词/排序, View 监听 `addListener` 重建
3. **Chips 动态生成**: `hexChips`/`dirChips`/`typeChips` 从当月记录聚合 (按计数排序), 跟易道 PWA 一致
4. **卦象缩略图**: 用 6 爻 mini-line 渲染 (金色实线/朱砂动爻), 非卦类记录显示徽标 (占法名首字)
5. **三屏 Hub**: IndexedStack 保留各屏状态 (滚动位置/选中 tab/筛选条件)

## 关键调试坑

1. **ViewModel 测试跨边界**: HistoryViewModel 继承 ChangeNotifier (flutter foundation), 不能用 `dart run` 纯 Dart 验证. 解决: 拆分为 `verify_engine.dart` (Repository 层) + `test/history_viewmodel_test.dart` (flutter_test). CI 跑后者
2. **lint info 阻塞 CI**: 4 个 info (`prefer_interpolation` / `sized_box_for_whitespace` / `avoid_single_cascade`) 再次触发 exit 1. 全部清掉 (清理后 0 issue)
3. **IndexedStack vs PageView**: 用 IndexedStack 保留各屏状态 (用户切回屏 6 仍保留滚动位置/筛选条件), PageView 会重建 → 选 IndexedStack
