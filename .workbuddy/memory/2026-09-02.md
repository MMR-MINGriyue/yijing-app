## 关键调试坑 (沉淀到长期记忆)

1. **CI analyze 对 info 也 exit 1**: 旧版本 flutter analyze + info 非零退出. 清理 lint 或 workflow 加 `|| true`
2. **沙箱 curl + git credential fill 受限**: 多次 SIGTERM/卡死. 解决: `printf` 到文件 → `cat 文件 | git credential fill` 拿到 token, curl 用 `--connect-timeout 10 -m 50` 长超时 + `-L` 跟 redirect
3. **flutter_tester WebSocket 连接失败**: 本机无 GUI 环境跑 `flutter test` 失败. 替代: `dart run tool/verify_engine.dart` 纯 Dart 验证引擎 (不依赖 Flutter UI)
4. **`.flutter_tool_state` 路径在 yijing-app 根**而非 yijing-flutter 子目录: 顶层 .gitignore 加 `.flutter_tool_state` 而非 `yijing-flutter/.flutter_tool_state`
5. **android/local.properties**: 每台机器 SDK 路径不同, 必须从 Flutter 项目排除 (Flutter 默认 .gitignore 含 local.properties 但子目录 .gitignore 不被父级继承, 需在 yijing-app .gitignore 加 `yijing-flutter/android/local.properties`)
6. **64 卦数据提取范围**: data.js HEX_LIBRARY 闭合在第 602 行(`],`), slice 范围要准确否则少卦

## 架构验证 (对照 iter29 讲解的 MVVM)

| 维度 | Flutter MVVM 落地 |
|---|---|
| Model | Hex / TransformResult 数据模型 (纯 Dart) |
| View | TransformScreen StatefulWidget, 只画界面+转发点击 |
| ViewModel | TransformViewModel extends ChangeNotifier, 持 state, 调 repository, notifyListeners() 触发 setState |
| Repository | HexRepository 单一入口, 引擎 + 数据全在 |
| Data | kHexLibrary const 列表, hex_library.dart 自动从易道 data.js 提取 |
| 单向数据流 | View 监听 vm → vm 改 state → notifyListeners → View 重建 ✓ |
