## 拆分方案

index.html 内联 script（4152 行，27 个 IIFE）拆为 `js/` 8 个架构层文件：

```
js/00-core.js      核心层: escapeHtml / HEX_DRAW_ORDER / YijingCalendar / YijingHistory / 时钟
js/01-init.js      初始化: 屏1最近占卜 / 屏3网格 / 屏2方法+方向 / 屏6分组注入
js/02-home-cast.js 屏1今日一卦(时辰卦/问候) + 屏3搜索过滤

js/05-detail.js    屏4卦辞解析(Tab/动态渲染) + 屏5爻辞Modal

```

关键: **保持 IIFE 顺序不变**（每段 = 连续 IIFE 块），依赖自然满足。

## 关键技术点

1. **顶层 const 跨文件不共享**: script 之间 `const`/`let` 是隔离的, 只有 `window.X = X` 挂载或顶层 `function` 声明（自动全局）可跨 script
2. **唯一例外 HEX_DRAW_ORDER**: 原是 `const HEX_DRAW_ORDER = [...]` 未挂 window → 改为 `window.HEX_DRAW_ORDER = [...]`
3. **其余共享符号已全部 window 挂载**: YijingCalendar / YijingHistory / YijingUI / buildHistoryRecord / bindHexFilters / YijingLayout / YijingAppMode / YijingShare（检查确认）
4. **切段行号偏移陷阱**: grep -n 编号是 awk 输出流内行号（从 1 开始）, 对应 body 0-based 需 -1. 首版切段全错了一个单位 → 所有文件 `Unexpected token '}'`
5. **加载顺序**: data.js → terms.js → divination.js → 00-core → ... → 07-extra
