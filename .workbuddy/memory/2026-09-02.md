## 屏 5 修复 (主要)

### 根因
- transform-slider `width: 100%` + 3 个 .hex-pair view 各 `min-width: 110px`, 横向总 362px > card 视口 292px
- transform `translateX(-100%)` 是相对 slider 100% = 292px, 但 view 间距基于 110px 实际宽度, 切换错位
- 结果: 3 view 全显示在 card 内, 推演 diff rows 6 行高度 259px 溢出 card 顶部

### 修复 (CSS)
```css
.transform-slider {
  display: flex; align-items: stretch;
  width: 300%; /* 3 view 横向并排 */
  flex-shrink: 0; /* 父级 flex 不压缩 300% */
  transition: transform 0.5s ...;
}
.hex-pair.view {
  width: calc(100% / 3);
  min-width: 0; /* 覆盖原 110px */
  display: flex; flex-direction: column;
  align-items: center; justify-content: center;
  gap: 10px;
  flex-shrink: 0;
}
.transform-card {
  flex-shrink: 0; /* 防止父级 .content 压扁 (view 高度 259px) */
  /* 去掉 justify-content: center (slider 300% 居中会让 view 0/2 看不到) */
}
```

### 修复 (JS)
```js
function goTo(idx, animate) {
```

## 调试坑

1. **flex-shrink 陷阱再发**: transform-card 在 .content flex column 里被压扁 (137px), 实际需要 301px 容纳 view 259+padding
2. **slider 300% 被压缩回 100%**: slider flex-shrink 默认 1, 父级 .transform-card 把它压回 100% — 加 flex-shrink: 0 修复
3. **justify-content: center 让 view 0/2 看不到**: slider 宽 870px 在 card 视口 292px 居中, 默认 view 0 在 -240 视口外, 看不到 — 改为 flex-start
4. **dot click 无效**: transformDots 没绑 click 事件, 切换 view 只能用 YijingUI.transformGoTo(idx) API 或拖拽
5. **Edge 浏览器路径变化**: 新会话 Playwright `channel: 'msedge'` 探测失败, 实际 Edge 在 `C:\Program Files (x86)\Microsoft\Edge\Application\msedge.exe` — 历史 iter 测试用 sed 改 `executablePath` 显式路径
