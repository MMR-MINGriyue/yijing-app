# 第六十七轮 — 功能层优化: 今日卦 + 命盘册备份 (v1.55.0)

## 需求: "ok，优化功能" (承接上轮建议, 两处都做)

## 1. 今日卦升级为按日期+时辰推演

- **关键算法取舍**: 初版直接用梅花 meiHuaByTime (年月日时起卦), 采样测试
  发现固定时辰时上下卦只随 (年+月+日)%8 变化 → 60 天仅 8 种卦,
  比旧 hourHex 的 16 卦循环还单调! 改用「日辰卦序法」:
  `UTC 连续日序 + shichenIndex(dt)` % 64 → 每天同时辰卦序 +1, 跨月连续,
  同一天 12 时辰偏移, 覆盖全部 64 卦 (60 天采样 = 60 卦)
- 新增 core/daily_hex.dart; HomeViewModel.todayHex 与 BaguaSplash.hexOf
  都改用 dailyHex (主页/启动动画严格同源); 主页文案
  「今日一卦 · 依时而定」→「今日一卦 · 依日时起卦」
- **hourHex 完全保留** (PWA 对拍基线), verify_engine 80 项仍全过
- 梅花时间起卦仍保留在占卜页作为门派算法, 未动

## 2. 八字命盘册纳入备份

- SettingsViewModel exportJson 加 `profiles` (名称→BaziBirth.toJson),
  importJson 按「同名不覆盖」合并, 返回文案含「N 个命盘」;
  旧版 PWA 导出无 profiles 时忽略缺失仍可导入
- 设置说明卡补 profiles 字段与命盘册说明
- **顺带修真 bug**: PrefsBaziBirthStore.warmUp 原在「当前盘为空」
  时提前 return → 命盘册永远读不出; 改不提前返回 + 过滤 null
- PrefsBaziBirthStore 改单例 (factory + 私有构造), 设置页导入后
  八字页立即读到同一份缓存 (installPrefsStores 工厂返回同一实例)
