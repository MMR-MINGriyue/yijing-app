## JS 语义仿真 (重要踩坑)

PWA `numbersFromText` (FNV-1a) Dart 直译结果错误! JS 三语义:
1. `^` 是 **Int32 有符号**异或 → Dart 要 `h1.toSigned(32) ^ c`
2. `*` 是 **double 乘**, |积|>2^53 时 53 位舍入 → Dart 要 `(x*16777619).toDouble().truncate()`
3. `>>>0` 对负数取 mod 2^32 → Dart `& 0xFFFFFFFF` (h1); h2 的和 < 2^38 无舍入, 位掩码即可
node BigInt 仿真逐位验证 8 组字符串全 MATCH, 向量 '近期事业运筹方向'→[4797,2131]
