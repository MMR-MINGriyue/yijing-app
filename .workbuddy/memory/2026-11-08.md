  (轻落定: 投币逐爻/换卦/收藏) / settle=mediumImpact(落定: 仪式完成/投币完成)
  / warn=heavyImpact(警示: 删除记录)

  / detail(收藏) / history(删除)

  `arguments as String` == 'HapticFeedbackType.lightImpact';
  误写 `arguments[0] as String` 会取到首字符 'H' (String 索引)
- 方法名 'HapticFeedback.vibrate'; mock handler 设在
  defaultBinaryMessenger.setMockMessageHandler('flutter/platform', ...)
- **pump 时长必须 ≥ 动画总长**: 6×430+260=2840ms, 前段 50+5×440 只覆盖
  逐爻触感, 尾段 pump 500ms 不到位 (2840>2750) → 完成触感缺第 6 次;
  尾段改 pump 800ms (至 3050ms) 通过
